# backend/api (chưa có code)

Khởi tạo dự án tại đây sau khi chốt ngôn ngữ (xem `../README.md`).

Yêu cầu khi hoàn thành:

- Đọc toàn bộ cấu hình từ biến môi trường (danh sách ở `.env.example` gốc repo). Không hard-code mật khẩu.
- Có `Dockerfile` để bật dịch vụ `backend` trong `deployment/docker-compose.yml`.
- Xuất tài liệu OpenAPI (Swagger) để làm mô hình "Mô tả API" bắt buộc.
- Có kiểm thử API tự động cho các ca ở `tests/scenarios.md` (đặt trong `tests/api/` hoặc trong dự án).
